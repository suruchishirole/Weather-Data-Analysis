# Weather-Data-Analysis
**_Weather Data Analysis 🌦️_**

**Project Overview**
  The Weather Data Analysis project is a Python-based application designed to load, clean, analyze, and visualize daily weather patterns over a 100-day period. It processes a dataset containing daily temperature, precipitation, and humidity records, calculates core meteorological metrics, and automatically generates professional charts to illustrate trends.
This project was built to demonstrate a complete data analysis pipeline using fundamental Python concepts and industry-standard data science libraries.

**Features**
1. Automated Data Cleaning: Uses Pandas to load CSV data, handle missing values, and convert date strings into usable datetime objects.
2. Statistical Analysis: Calculates key metrics such as Average Temperature, Maximum Temperature, and Total Precipitation.
3. Data Visualization: Automatically generates and saves Matplotlib charts:
4. 📈 Line Chart: Tracks daily temperature fluctuations over 100 days.
5. 📊 Bar Chart: Aggregates and displays total precipitation grouped by month.
6. Automated Reporting: Generates a formatted Markdown report summarizing the findings and metrics.

**Technologies Used**
<br>Python 3.x
<br>Pandas (Data manipulation and analysis)
<br>Matplotlib (Data visualization)
